# Using our Claude Code plugins in Docker Sandboxes

An example project that shows how to run Claude Code inside a
[Docker Sandbox](https://docs.docker.com/ai/sandboxes/) (`sbx`) with the
team's plugins from
[cap_skills](https://github.com/Cellular-Semantics/cap_skills), pinned per project with
[cs-plugin](https://github.com/ubyndr/cs-plugin).

It has no workflow code of its own: only the plugin pins, the files cs-plugin
generates from them, and recorded example runs.

## What's here

| Path | What it is |
|---|---|
| [GUIDE.md](GUIDE.md) | setup from scratch: uv, sbx, network policy, sandbox, installing the pinned plugins, running skills |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | fixes for common problems, including a machine whose network policy is not balanced |
| [examples/](examples/) | prompts run in the sandbox, with their recorded output |
| [scripts/sbx-claude.sh](scripts/sbx-claude.sh) | run one prompt with Claude inside the sandbox, from the laptop |
| [scripts/sbx-policy-rebalance.sh](scripts/sbx-policy-rebalance.sh) | switch a machine's network policy to balanced, keeping its custom rules |
| `plugins.toml` | the pinned plugins (edit with `cs-plugin add/remove/upgrade`) |
| `.claude/` | generated by cs-plugin: the project's plugin marketplace and settings |

## Quick start

Once uv, sbx and the network policy are set up ([GUIDE.md](GUIDE.md) steps
1–4):

```sh
git clone https://github.com/Cellular-Semantics/sbx-plugin-guide.git
cd sbx-plugin-guide
sbx create --name my-project claude .
sbx exec -e PROJ="$PWD" my-project bash -lc 'cd "$PROJ" && uv tool run --from "git+https://github.com/ubyndr/cs-plugin@pkg-cs-plugin--v0.1.1#subdirectory=packages/cs-plugin" cs-plugin sync'
sbx run --name my-project        # type /login once, then try a prompt from examples/
```

Or without opening a session:

```sh
./scripts/sbx-claude.sh my-project "/cap-tools:cap-datasets list Human Cell Atlas datasets about the lung"
```

Or call the `cap` CLI the skills use, without Claude (see
[examples/03-cap-cli.md](examples/03-cap-cli.md)):

```sh
sbx exec my-project bash -lc 'uv tool run --from "git+https://github.com/Cellular-Semantics/cap_skills@v0.4.0#subdirectory=packages/cap-client" cap datasets --consortium "Human Cell Atlas" --name lung --format text'
```
